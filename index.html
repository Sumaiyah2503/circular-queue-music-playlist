01 • CONCEPT

What is a Circular Queue?

A simple exam-ready explanation of the concept.

🔄
DEFINITION

Circular Queue

A Circular Queue is a linear data structure in which the last position is connected back to the first position, forming a circle.

🧠 Remember: Last Position → First Position → Continue Again
01

Front

Points to the first element that will be processed or removed.

02

Rear

Points to the position where a new element is inserted.

03

FIFO

First In, First Out — first song added is processed first.

04

Wrap Around

After index 9, the next position becomes index 0.

02 • QUEUE STATE

How do we know the Queue State?

The count tells us whether the queue is empty, full or has available space.

🫧
EMPTY

count == 0

No songs are present in the queue.

🌱
AVAILABLE

0 < count < 10

There is still space to add songs.

🔴
FULL

count == 10

Queue is full and no new song can be added.

🧠
EXAM MEMORY TRICK

count = 0 → EMPTY   |   count = 10 → FULL   |   Between → AVAILABLE

CIRCULAR MOVE

🔄 Move Forward

Front or Rear moves using modulo.

%
CIRCULAR FORMULA

Next Position = (Current + 1) % Capacity

Example: (9 + 1) % 10 = 0

05 • EXAM READY

Pseudocode

Easy pseudocode that you can remember for exams.

＋
OPERATION 01

ENQUEUE — Add Song

ENQUEUE(song)

IF count == capacity
    Display "Queue Full"
ELSE
    rear = (rear + 1) % capacity
    queue[rear] = song
    count = count + 1
END IF
▶
OPERATION 02

DEQUEUE — Play Song

DEQUEUE()

IF count == 0
    Display "Queue Empty"
ELSE
    Play queue[front]
    front = (front + 1) % capacity
    count = count - 1
END IF

🧠 Most Important Formula

(current + 1) % capacity

This formula makes the queue circular.
